## Why that is dangerous here

The failure mode for the Pattern B change is *silence*. If `EGTKPhysics.TryAddImpulse` selects the
wrong branch, the component still compiles and simply stops applying force. For the 11 uncovered
scripts nothing in this project would reveal it — not the compiler, not any scene, not a student
until the next semester.

## Consequence for the plan

The regression gate is **PlayMode tests written before each change**, not scene observation:

1. Write a PlayMode test asserting the component's current 3D behavior.
2. Run it. It must **pass against unmodified code** — that is what makes it a gate. A test written
   after the change only documents whatever the new code does.
3. Make the change.
4. Run it again. Still passing means no 3D regression.
5. Add a 2D variant of the test.

Scene checks remain useful for the 8 covered scripts, but they are corroboration, not the gate.
